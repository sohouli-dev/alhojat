همیشه قبل از اینکه دست به کد بشی، اول آخرین تغییرات رو از گیت‌هاب بگیر توی سیستمِت تا با آخرین نسخه جلو بری:
git pull
موقعی که کارت تموم میشه و می‌خوای بری (یا سیستم رو خاموش کنی):
git add .
git commit -m "توضیح کوتاهی از کاری که امروز انجام دادی"
git push
